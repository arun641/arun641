## About Me

I'm a System Administrator with 5+ years of hands-on experience in IT infrastructure, endpoint security, and network operations — currently transitioning into a **DevOps / Cloud Infrastructure** role.

My work spans Linux server administration, Windows Server environments, SIEM operations (Wazuh), endpoint security (Trend Micro Apex One, Netwrix DLP), and network security (FortiGate, SonicWall, pfSense). I'm now building on that foundation to design, automate, and secure cloud-native infrastructure using modern DevOps tooling.
